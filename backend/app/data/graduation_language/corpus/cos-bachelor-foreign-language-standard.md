# 國立中央大學理學院外文能力鑑定考試合格標準

國立中央大學理學院外文能力鑑定考試合格標準
  113.12.24 理學院院務會議通過
  114.3.19 教務會議通過
  115.2.24 理學院院務會議通過
  115.3.24 教務會議通過
一、 理學院(以下簡稱本院)為提升學生國際移動力及職涯競爭力，並積極培養多元外文能
  力，特依本校學則第四十八條第一項第二款規定訂定本標準。
二、 適用對象：108學年度起本院大學部學生。
三、 本院大學部學生須於畢業前，自行報考第四點所列各項外文檢定考試其中至少一項
  (含)，且成績達該項考試合格標準。無法達到其中一項外文檢定考試成績合格標準者，
  得依本校「大一外文暨進修英文修課及教學實施辦法」第六條及「英文能力鑑定暨進
  修英文課程實施細則」第四條規定辦理。
四、 本院認定之外文能力鑑定考試及合格標準：
