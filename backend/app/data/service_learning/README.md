# 服務學習規定

`requirements.json` 是 `GET /api/v1/intl/service-learning` 的資料，人工整理，2026-11-10 對照原文。

## 收錄原則

- 規則只收完整讀過的官方文件，每條附網址與原文引述。
- 只在搜尋摘要看到、或網頁打不開的內容，不寫成規則，放進 `open_questions`。
- `title_en`、`summary_en`、`summary_zh` 是我們自己的整理，原文以 `quote` 為準。
