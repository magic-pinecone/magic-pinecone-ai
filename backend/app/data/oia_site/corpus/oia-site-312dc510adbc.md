1.1. 學生個人資料維護 Student Personal Information Maintenance
功能名稱
Function
學生個人資料維護
Student Personal Information Maintenance
功能說明
Description
所有使用者之個人基本資料與密碼修改
Student Personal personal information and password
操作步驟 Step 操作畫面 Operation Screen
依第二章申辦網登入操作登入
後，顯示網站首頁，點選「基本資
料維護 > 305_學生個人資料維
護」，顯示個人資料維護頁面
After logging in to the website
according to the steps in “二
Application Website Login”, you
will see the homepage. Click
“Maintain basic information >
305_Student Personal Information
Maintenance” to show the “Maintain
personal information” webpage.
輸入相關修改資料或個人密碼，點
選【確定】，網站會提示修改成功
之訊息
Revise personal information or
password, and click “Confirm”. The
website will show a window
indicating that the information has
been successfully revised.

1.2. 學生案件管理 Student Application Management
功能名稱
Function
學生案件管理
Student Application Management
功能說明
Description
學生查詢及維護申請之案件
Review and manage students’ applications.
操作步驟 Step 操作畫面 Operation Screen
依「第二章學生帳號/密碼登入」
登入網站後，可透過「案件管理 >
260_學生案件管理」頁面進行案件
之維護
After logging in to the website
according to the steps in “二
Website Login”. Click “Case
Management > 260_Student
Application Management”.
點選查詢結果的案件序號或是後
方的案件動作按鈕(如訂補正建
立)，可進行案件的一般申請操作
(如繼續未完成送出之案件)，或其
他訂補正相關操作：
 訂正：參考第八章學生案件訂
正
 補正：參考第八章學生案件補
正
Click the case number of the action
button in the rear (such as Revise) to
process the regular operation of the
application (such as, continue with
the unfinished application), or revise
related operation:
 Revision: Refer to 八
Application Revision
 Correction: Refer to 八
Application Correction

1.3. 學生行動裝置檢視專區 Electronic Service of Student Work Permit.
功能名稱
Function
行動裝置檢視專區
Electronic Service of Student Work Permit.
功能說明
Description
行動裝置檢視下載
Download the Electronic Service of student Work Permit
操作步驟 Step 操作畫面 Operation Screen
依「第二章學生帳號/密碼登入」
登入網站後，可透過「案件管理 >
261_行動裝置檢視專區」頁面進行
案件之維護
After logging in to the website
according to the steps in “二
Website Login”. Click “Case
Management > 261_ Electronic
Service of Student Work Permit”.
點選【行動裝置檢視下載】，確
認案件資訊後，進行列印，或下載
PDF 檔。
Click [Download the Electronic
Service of student Work Permit],
confirm the case information, print
it, or download the PDF file.
 貼心小提醒
此為行動裝置檢視"工作許可資訊"，僅作為有工作許可的佐
證，但不能當作工作證
（工作許可領取簡介流程可參閱第七章電子公文領取）。
This is a mobile device view of "Work Permit Information"
and is only used as proof of having a work permit.
(The introduction process of receiving work permits can
be found in Chapter 7 Receive the Electronic Document ).
