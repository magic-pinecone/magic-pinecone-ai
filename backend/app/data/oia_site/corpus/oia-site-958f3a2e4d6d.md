# 僑生畢業離校流程

僑生畢業離校流程說明如下，請即將畢業的僑生務必完成以下事項：
1. 請主動與系所確認是否有任何需要填寫的離校資料或繳交的文件。
2. 請確認圖書館、體育室或其他單位借的東西是否已還。
3. 請填寫國際處「國立中央大學僑生離校資料表」(如
附件
<https://oia.ncu.edu.tw/p/phocadownload/overseas-chinese/guo%20li%20zhong%20yang%20da%20xue%20qiao%20sheng%20li%20xiao%20zi%20liao%20biao-OIA2022701.pdf>
)後，e-mail回傳國際處徐心荷小姐(
lotus@ncu.edu.tw
)，國際處收到檔案後會再協助學生線上檢核離校。
4. 請依照註冊組規定領取畢業證書時間，前往註冊組領取畢業證書。
注意事項：若是住在中大宿舍的同學，依照住宿服務組的規定，領取畢業證書當天則同時需搬離中大宿舍。
5. 請完成離校流程(領取畢業證書)的同學留意以下事項：
(1) 如果是要返國的同學，請於移民署規定10天內須離台，畢業生的居留證則無法再出入境使用。港澳生需在出境前前往移民署辧理單次出境證。
(2) 如果是要在台找工作的同學，建議正式離校後10天內，到移民署網站上申辦留台找工作的居留證。
