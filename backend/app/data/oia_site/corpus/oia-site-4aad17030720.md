# IIPP 計劃

計畫介紹
本計畫為國科會為國基科研人才打造來臺實習的優質管道，體驗臺灣頂尖研究環境。提供學生深入了解臺灣科研實力的機會，進而選擇在臺深造或就業，為臺灣的科研發展注入新動能！
官方網站：
https://iipp.tw/
<https://iipp.tw/>
計畫內容
申請方式：教授和海外學生可分別至 IIPP 官方網站註冊申請
申請期間：2025 年申請截止日為 9/15 (星期一)。實習時間最短 28 天，最長 90 天，每月不住海外學生至多3萬元，並須於結束後提交報告。
注意事項
計畫主持人於實習期間需給予實習生適當研究指導，並協助與臺灣學生互動交流及認識臺灣多元文化；實習生須依參與計畫之研究主題及領域，進行相關研究與學習。
每位計畫主持人(PI)至多可提供2個實習空缺。
海外學生應於開始計畫前3個月完成申請，IIPP系統每個月15日會關閉系統作業流程。(如2025年計畫至2026年2月結束，系統申請作業就會在9/15關閉)
學生需為目前於海外學校註冊的外籍生（不得為中港澳臺生）；不得同時支領臺灣相關獎助學金且不得與領取相關獎助之專案並行。
接待實習生之系所，應協助學生向住宿服務組申請床位，或尋找校外住宿。
學生須自行提供保險證明。
學生於實習期間須繳交報告，系統會根據實習期間長短發送提醒信，繳交日期原則上是每月21日，PI須至平台確認報告內容並簽署核准。
學生每月實習經費為新台幣3萬元，以簽領支票方式提供。實習經費提供時間將以IIPP經費入帳時間而定。
